# GitHub Pages hosting

Source: https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages

Reviewed working note, 2026-10-29. This is project-relevant paraphrased knowledge; full fetched page Markdown is retained locally, not republished here.

GitHub Pages serves a static website from a repository and can use a build workflow. Project sites live below an owner.github.io repository path. This app can use it because its model, editor and browser-local state run on the client. It supplies no application server for shared model edits; view links carry camera state rather than another visitor’s local arrangements.
