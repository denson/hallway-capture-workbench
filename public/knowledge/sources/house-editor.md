# Image to 3D House Editor

Source: https://github.com/wit543/image-to-3d-house-editor

Reviewed working note, 2026-10-29. This is project-relevant paraphrased knowledge; full fetched page Markdown is retained locally, not republished here.

The upstream repository is a reusable Three.js house editor. It supplies navigation, object editing, saved arrangements and model/image exports. Its workflow has an agent author geometry from images and floor plans; it is not a self-contained automatic image-to-model service. This hallway project adapts that editor rather than implementing an unrelated viewer. The upstream source and documentation remain the attribution point; do not assume that the unrelated Blender demonstration uses this code.
