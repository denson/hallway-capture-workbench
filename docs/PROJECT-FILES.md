# Save and open a complete project

1. Click **Save project** in the top bar. One file named `my-house.house-project.json` downloads to your computer.
2. Keep that file as your backup, or send it to someone using this editor.
3. Click **Open project** and select the file to restore it. Opening replaces the current scene, so save your current project first.

The file includes the base model geometry and embedded textures, current object positions, rotations, sizes, names, finishes, duplicates and deletions, your custom asset catalog and all named designs. It also restores viewing mode, roof visibility, room labels and daylight setting. Deleted built-in objects can still be added from the restored catalog.

Saving downloads a file; it does not publish your design or upload it to a cloud account. Save again after making changes. Loading opens the project for this session; after refreshing the website, use Open project again. Keep the file outside browser storage as your durable backup.

**Save arrangement** and **Save named design** are browser saves. **Layout** downloads only placement recipes for the same model. **Save project** is the complete editable model backup. PNG, GLB and measured SVG exports are viewing/interchange formats, not complete editor backups.

## Scope and compatibility

Use a compatible version of this house editor to open the file (format version 1, maximum 100 MB). The file does not contain the website source code, undo history, exact camera viewpoint or private reference photos. Navigation room shortcuts, room labels, environment lighting and editor tools come from the viewer application. For a different house, update those definitions with Codex too. Project files include the textures intended for the website, so check their contents before sharing.

## Try it

Resize a chair to 1.25 m wide, save it to the catalog, and save a named design. Click Save project. Change the chair width to 1.70 m, then Open project with your saved file. The chair returns to 1.25 m and your catalog and design options return with it.
